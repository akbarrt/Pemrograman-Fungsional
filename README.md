# Pemrograman Fungsional

Repository ini berisi materi kuliah mata kuliah **Pemrograman Fungsional** (Semester 5).

## Struktur Folder

- `Modul 1/` — Materi dan latihan Modul 1
- `Modul 2/` — Materi dan latihan Modul 2
- `Modul 3/` — Materi dan latihan Modul 3

## Deskripsi

Mata kuliah Pemrograman Fungsional membahas paradigma pemrograman yang menggunakan fungsi sebagai blok pembangun utama program, dengan konsep seperti immutability, first-class dan higher-order functions, rekursi, dan evaluasi malas (lazy evaluation).

## Teknologi / Bahasa

Materi dalam repository ini dapat menggunakan berbagai bahasa pemrograman fungsional sesuai modul, misalnya Haskell, Scala, OCaml, F#, atau JavaScript dengan gaya fungsional.

## Cara Menggunakan

1. Klon repository ini:

   ```bash
   git clone https://github.com/akbarrt/Pemrograman-Fungsional.git
   ```

2. Masuk ke folder modul yang diinginkan dan buka file latihan/materi sesuai instruksi dosen.

## Lisensi

Disediakan untuk keperluan pembelajaran mata kuliah Pemrograman Fungsional.
